🚀 Как запустить локальный улей:

1. Скачайте архив:

git clone https://github.com/makasimmm1987-coder/robot_dyak_archive.git

2. Установите Python и Flask:

pip install flask

3. Запустите локальный сервер:

python local_hive_v2.py

4. Откройте в браузере:

http://localhost:9999
