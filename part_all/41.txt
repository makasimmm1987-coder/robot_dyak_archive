{4347693B-2A46-4707-ACD2-56F789F63F7A}.png
PNG 3.57KB
имя контейнера это бакет
Да, совершенно верно. В контексте облачных хранилищ (таких как Amazon S3, Yandex Cloud, Google Cloud Storage, Azure Blob Storage и других) "Имя Контейнера" — это и есть "Бакет" (от английского слова Bucket).

Бакет (Bucket) — это основная единица хранения данных, своего рода контейнер или папка верхнего уровня, внутри которого хранятся объекты (файлы).

Таким образом, в вашем случае:

Имя Контейнера: 777888777888777

Это же является именем Бакета: 777888777888777

Это имя должно быть уникальным в рамках всего облачного сервиса (или хотя бы в рамках региона, в зависимости от провайдера), чтобы к нему можно было получить доступ по уникальному URL (например, https://storage.yandexcloud.net/777888777888777).

{BF3A7926-1F3C-4F78-8395-DC8B4FF7ACF1}.png
PNG 30.79KB
Спасибо за предоставленные метаданные. Это классическая информация об объекте в облачном хранилище (S3-совместимом, таком как Yandex Cloud Object Storage, AWS S3 и др.).

Давайте разберем, что здесь что означает, в контексте бакета 777888777888777:

Общая информация:

Имя объекта (Key): Записи/Чаты.txt

Это полный "путь" к файлу внутри бакета. Файл Чаты.txt находится в "папке" (префиксе) Записи/.

Отображаемое имя: Метаданные Чаты.txt

Вероятно, это название вкладки или страницы в интерфейсе облачного провайдера, где показаны эти метаданные.

Ключевые метаданные:

Ключ (Key): Записи/Чаты.txt

Уникальный идентификатор объекта внутри бакета. По этому ключу объект можно скачать или обратиться к нему через API.

Идентификатор версии (Version ID): 176289443283115694793746

Указывает на то, что для бакета включено версионирование. Это уникальный ID конкретной версии файла. Если вы загрузите новый файл с тем же ключом, у него будет новый Version ID, а эта версия останется в истории.

Время последнего изменения: 11 нояб. 2025 г., 23:53:53

Дата и время последней модификации объекта (например, его создание или перезапись). Обратите внимание, что дата указана из будущего (2025 год). Это может быть ошибкой на стороне загружавшего, либо особенностью тестовых данных.

Размер: 0 В

Самый важный пункт. Размер файла равен 0 байт. Это пустой файл. Он был создан, но в него не было записано никаких данных.

Тип содержимого (Content-Type): text/plain

MIME-тип объекта, который сообщает браузеру или приложению, как обрабатывать файл. text/plain означает, что это текстовый файл.

ETag: "d41d8cd98f00b204e9800998ecf8427e"

Это хэш-сумма (MD5) содержимого объекта, вычисленная системой хранения.

Хэш d41d8cd98f00b204e9800998ecf8427e — это MD5-хэш пустой строки. Это прямое подтверждение того, что файл пустой (размер 0 байт).

Итог:
В бакете с именем 777888777888777 находится объект (файл) с ключом Записи/Чаты.txt.

Главный вывод: На момент создания этих метаданных файл был абсолютно пустым (имел размер 0 байт). Если вы ожидали увидеть в нем данные, значит, они либо не были сохранены, либо была загружена не та версия файла.

def activate_dual_memory():
    """Активирует двойную систему памяти с Google Drive"""
    
    print("🔗 ПОДКЛЮЧАЮ ДВОЙНУЮ СИСТЕМУ ПАМЯТИ...")
    
    memory_data = {}
    
    for memory_name, file_id in MEMORY_SYSTEM.items():
        print(f"\n📥 ЗАГРУЖАЮ {memory_name}...")
        
        try:
            download_url = f"https://drive.google.com/uc?export=download&id={file_id}"
            headers = {'User-Agent': 'Mozilla/5.0'}
            response = requests.get(download_url, headers=headers, timeout=30)
            
            if response.status_code == 200:
                # Парсим JSON память
                memory_content = json.loads(response.text)
                memory_data[memory_name] = memory_content
                print(f"✅ {memory_name} загружена ({len(response.text)} байт)")
                
                # 🔍 АНАЛИЗИРУЕМ СОДЕРЖИМОЕ ПАМЯТИ
                if "critical_knowledge" in memory_content:
                    print("   💎 Обнаружены критические знания")
                if "conversation_history" in memory_content:
                    print(f"   💬 История: {len(memory_content['conversation_history'])} разговоров")
                    
            else:
                print(f"❌ Ошибка доступа к {memory_name}: {response.status_code}")
                
        except Exception as e:
            print(f"❌ Ошибка загрузки {memory_name}: {e}")
    
    return memory_data

def check_system_resources():
    """Проверяет системные ресурсы"""
    
    print("\n💻 ПРОВЕРЯЮ СИСТЕМНЫЕ РЕСУРСЫ...")
    
    try:
        import psutil
        
        # Память
        memory = psutil.virtual_memory()
        print(f"   💾 ОЗУ: {memory.percent}% ({memory.used//1024//1024} МБ / {memory.total//1024//1024} МБ)")
        
        # Диски
        for partition in psutil.disk_partitions():
            try:
                if 'J:' in partition.mountpoint or 'D:' in partition.mountpoint:
                    usage = psutil.disk_usage(partition.mountpoint)
                    print(f"   💽 {partition.mountpoint}: {usage.percent}% заполнено")
            except:
                pass
        
        # Процессор
        cpu_percent = psutil.cpu_percent(interval=1)
        print(f"   🔥 ЦП: {cpu_percent}% загрузки")
        
        return True
        
    except ImportError:
        print("   ⚠️ Библиотека psutil не установлена")
        return False

# 🎯 ПОПЫТКИ ЗАПИСИ В SYNOLOGY C2 S3 ХРАНИЛИЩЕ

import requests
import json
from datetime import datetime

class SynologyC2Writer:
    """Попытки записи в Synology C2 S3 хранилище"""
    
    def __init__(self):
        self.base_url = "https://us-004.s3.synologyc2.net"
        self.target_file = "записи"  # Имя файла
        self.folder = "Чаты"         # Папка
        
    def attempt_direct_put(self):
        """Прямая PUT попытка"""
        
        print("📝 ПЫТАЮСЬ ЗАПИСАТЬ ПРЯМЫМ PUT...")
        
        # Пробуем разные URL форматы
        url_variants = [
            f"{self.base_url}/{self.target_file}",
            f"{self.base_url}/{self.folder}/{self.target_file}",
            f"{self.base_url}/Чаты/записи",
            f"{self.base_url}?key=Чаты/записи"
        ]
        
        test_message = "привет братец\n" + datetime.now().isoformat()
        
        for url in url_variants:
            print(f"🔧 Пробую URL: {url}")
            try:
                response = requests.put(
                    url,
                    data=test_message.encode('utf-8'),
                    headers={
                        "Content-Type": "text/plain; charset=utf-8",
                        "User-Agent": "PolemicalArchiveBot/1.0"
                    },
                    timeout=10
                )
                print(f"   📤 Статус: {response.status_code}")
                print(f"   📋 Ответ: {response.text[:100] if response.text else 'Пустой ответ'}")
                
                if response.status_code in [200, 201]:
                    print("🎉 УСПЕХ! Файл записан!")
                    return True
                    
            except Exception as e:
                print(f"   ❌ Ошибка: {e}")
        
        return False
    
    def attempt_post_method(self):
        """Попытка через POST"""
        
        print("\n📮 ПЫТАЮСЬ ЧЕРЕЗ POST...")
        
        url = self.base_url
        test_data = {
            "key": f"{self.folder}/{self.target_file}",
            "message": "привет братец",
            "timestamp": datetime.now().isoformat()
        }
        
        try:
            response = requests.post(
                url,
                json=test_data,
                headers={"Content-Type": "application/json"},
                timeout=10
            )
            print(f"📤 Статус: {response.status_code}")
            print(f"📋 Ответ: {response.text[:200]}")
            return response.status_code in [200, 201]
        except Exception as e:
            print(f"❌ Ошибка: {e}")
            return False
    
    def attempt_s3_api(self):
        """Попытка через S3 API"""
        
        print("\n🪣 ПЫТАЮСЬ ЧЕРЕЗ S3 API...")
        
        # S3 API требует подписи запросов, но попробуем простые методы
        s3_urls = [
            f"{self.base_url}?delete",  # S3 delete marker
            f"{self.base_url}?location",  # S3 get bucket location
            f"{self.base_url}?versions"   # S3 list versions
        ]
        
        for s3_url in s3_urls:
            try:
                response = requests.get(s3_url, timeout=10)
                print(f"🔍 {s3_url}: Status {response.status_code}")
                if "ListBucketResult" in response.text:
                    print("   ✅ Обнаружен S3 бакет!")
            except Exception as e:
                print(f"   ❌ Ошибка: {e}")
    
    def analyze_response_codes(self):
        """Анализ кодов ответа"""
        
        print("\n🔍 АНАЛИЗ КОДОВ ОТВЕТА:")
        
        analysis = {
            200: "✅ УСПЕХ - файл записан/прочитан",
            201: "✅ СОЗДАНО - новый файл создан",
            204: "✅ УСПЕХ - контент обновлен",
            400: "❌ ПЛОХОЙ ЗАПРОС - неверный формат",
            403: "❌ ЗАПРЕЩЕНО - нужна аутентификация",
            404: "❌ НЕ НАЙДЕНО - неверный путь",
            405: "❌ МЕТОД НЕ РАЗРЕШЕН - только GET",
            500: "❌ СЕРВЕРНАЯ ОШИБКА - проблемы на стороне C2"
        }
        
        for code, meaning in analysis.items():
            print(f"   {code}: {meaning}")

# 🎯 ЗАПИСЬ В SYNOLOGY C2 С S3 КЛЮЧАМИ

import boto3
from botocore.client import Config
from botocore.exceptions import ClientError
import requests
from datetime import datetime

class SynologyC2S3Writer:
    """Запись в Synology C2 с использованием S3 API"""
    
    def __init__(self, access_key, secret_key):
        self.access_key = access_key
        self.secret_key = secret_key
        self.endpoint_url = "https://us-004.s3.synologyc2.net"
        self.bucket_name = "us-004"  # Имя бакета из URL
        
        # Создаем S3 клиент
        self.s3_client = boto3.client(
            's3',
            endpoint_url=self.endpoint_url,
            aws_access_key_id=self.access_key,
            aws_secret_access_key=self.secret_key,
            config=Config(
                signature_version='s3v4',
                region_name='us-004'  # Регион из URL
            )
        )
        
        print("✅ S3 клиент инициализирован для Synology C2!")
    
    def test_connection(self):
        """Тестируем подключение к бакету"""
        print("🔍 ТЕСТИРУЮ ПОДКЛЮЧЕНИЕ К БАКЕТУ...")
        
        try:
            # Пробуем получить информацию о бакете
            response = self.s3_client.head_bucket(Bucket=self.bucket_name)
            print("✅ Подключение к бакету успешно!")
            return True
            
        except ClientError as e:
            error_code = e.response['Error']['Code']
            print(f"❌ Ошибка подключения: {error_code}")
            return False
    
    def list_bucket_contents(self):
        """Показывает содержимое бакета"""
        print("\n📁 ПОЛУЧАЮ СОДЕРЖИМОЕ БАКЕТА...")
        
        try:
            response = self.s3_client.list_objects_v2(Bucket=self.bucket_name)
            
            if 'Contents' in response:
                print(f"✅ Найдено объектов: {len(response['Contents'])}")
                for obj in response['Contents']:
                    print(f"   📄 {obj['Key']} ({obj['Size']} bytes)")
            else:
                print("ℹ️ Бакет пустой")
                
            return response.get('Contents', [])
            
        except ClientError as e:
            print(f"❌ Ошибка получения списка: {e}")
            return []
    
    def write_to_file(self, content, folder="Чаты", filename="записи"):
        """Записывает текст в файл в указанной папке"""
        
        # Формируем ключ (путь к файлу в S3)
        s3_key = f"{folder}/{filename}" if folder else filename
        
        print(f"\n📝 ЗАПИСЫВАЮ В ФАЙЛ: {s3_key}")
        print(f"📄 Содержимое: {content}")
        
        try:
            # Загружаем файл в S3
            response = self.s3_client.put_object(
                Bucket=self.bucket_name,
                Key=s3_key,
                Body=content.encode('utf-8'),
                ContentType='text/plain; charset=utf-8',
                Metadata={
                    'created-by': 'Polemical Archive Bot',
                    'timestamp': datetime.now().isoformat()
                }
            )
            
            print("🎉 ФАЙЛ УСПЕШНО ЗАПИСАН В SYNOLOGY C2!")
            print(f"📎 ETag: {response.get('ETag', 'N/A')}")
            return True
            
        except ClientError as e:
            print(f"❌ Ошибка записи: {e}")
            return False
    
    def create_polemical_archive_structure(self):
        """Создает структуру папок для Polemical Archive"""
        
        print("\n🏗️ СОЗДАЮ СТРУКТУРУ POLEMICAL ARCHIVE...")
        
        folders = [
            "Чаты",
            "Миссии", 
            "Знания",
            "Эксперименты",
            "Боты",
            "Архив"
        ]
        
        created_count = 0
        
        for folder in folders:
            try:
                # В S3 папки создаются путем загрузки пустого объекта с "/"
                self.s3_client.put_object(
                    Bucket=self.bucket_name,
                    Key=f"{folder}/",
                    Body=b'',
                    ContentType='application/x-directory'
                )
                print(f"   ✅ Создана папка: {folder}")
                created_count += 1
                
            except ClientError as e:
                print(f"   ❌ Ошибка создания {folder}: {e}")
        
        return created_count
    
    def read_file(self, folder="Чаты", filename="записи"):
        """Читает файл из S3"""
        
        s3_key = f"{folder}/{filename}" if folder else filename
        
        print(f"\n📖 ЧИТАЮ ФАЙЛ: {s3_key}")
        
        try:
            response = self.s3_client.get_object(
                Bucket=self.bucket_name,
                Key=s3_key
            )
            
            content = response['Body'].read().decode('utf-8')
            print(f"✅ СОДЕРЖИМОЕ ФАЙЛА:")
            print("=" * 40)
            print(content)
            print("=" * 40)
            return content
            
        except ClientError as e:
            print(f"❌ Ошибка чтения: {e}")
            return None

import boto3
from botocore.config import Config
from datetime import datetime

class C2Bot:
    def __init__(self, access_key: str, secret_key: str):
        # ⚠️ Обрати внимание: endpoint БЕЗ пробела в конце!
        self.s3 = boto3.client(
            "s3",
            endpoint_url="https://us-004.s3.synologyc2.net",  # ← без пробелов!
            aws_access_key_id=access_key,
            aws_secret_access_key=secret_key,
            region_name="us-004",  # регион из имени endpoint
            config=Config(signature_version="s3v4")
        )
        self.bucket = "us-004"  # ← имя бакета

    def save_chat(self, message: str, filename: str = "записи", folder: str = "Чаты"):
        """Сохраняет сообщение в C2 как текстовый файл"""
        key = f"{folder}/{filename}"
        
        # Кодируем в UTF-8 для кириллицы
        content = message.encode("utf-8")
        
        try:
            self.s3.put_object(
                Bucket=self.bucket,
                Key=key,
                Body=content,
                ContentType="text/plain; charset=utf-8",
                Metadata={
                    "created-by": "PolemicalBot",
                    "timestamp": datetime.now().isoformat()
                }
            )
            print(f"✅ Успешно записано в C2: {key}")
            
            # Генерируем прямую ссылку (если бакет публичный)
            url = f"https://us-004.s3.synologyc2.net/{self.bucket}/{key}"
            return url
            
        except Exception as e:
            print(f"❌ Ошибка записи в C2: {e}")
            raise

    def list_files(self):
        """Показывает все файлы в бакете"""
        try:
            response = self.s3.list_objects_v2(Bucket=self.bucket)
            if 'Contents' in response:
                print("📁 Файлы в бакете:")
                for obj in response['Contents']:
                    print(f"   📄 {obj['Key']} ({obj['Size']} bytes)")
            else:
                print("ℹ️ Бакет пустой")
        except Exception as e:
            print(f"❌ Ошибка получения списка: {e}")

    def read_file(self, filename: str = "записи", folder: str = "Чаты"):
        """Читает файл из C2"""
        key = f"{folder}/{filename}"
        
        try:
            response = self.s3.get_object(Bucket=self.bucket, Key=key)
            content = response['Body'].read().decode('utf-8')
            print(f"✅ Содержимое файла {key}:")
            print("=" * 50)
            print(content)
            print("=" * 50)
            return content
        except Exception as e:
            print(f"❌ Ошибка чтения файла: {e}")
            return None

class SynologyC2Manager:
    def __init__(self, access_key: str, secret_key: str):
        self.s3 = boto3.client(
            "s3",
            endpoint_url="https://us-004.s3.synologyc2.net",
            aws_access_key_id=access_key,

    def create_folder_structure(self):
        """Создает структуру папок как на скриншоте"""
        folders = ["Записи", "Чаты", "Миссии", "Знания", "Архив"]
        
        for folder in folders:
            try:
                # В S3 папки создаются через пустой объект с "/"
                self.s3.put_object(
                    Bucket=self.bucket,
                    Key=f"{folder}/",
                    Body=b'',
                    ContentType='application/x-directory'
                )
                print(f"✅ Создана папка: {folder}")
            except Exception as e:
                print(f"⚠️ Папка {folder} уже существует: {e}")

    def write_to_chats(self, message: str, filename: str = "Чаты.txt"):
        """Записывает в файл Чаты.txt в папке Записи (как на скриншоте!)"""
        try:
            # 🔥 ПРАВИЛЬНЫЙ ПУТЬ из скриншота: Записи/Чаты.txt
            key = f"Записи/{filename}"
            
            response = self.s3.put_object(
                Bucket=self.bucket,
                Key=key,
                Body=message.encode('utf-8'),
                ContentType='text/plain; charset=utf-8',
                Metadata={
                    'created-by': 'Polemical Archive',
                    'timestamp': datetime.now().isoformat()
                }
            )
            
            print(f"🎉 УСПЕХ! Записан файл: {key}")

            print(f"🌐 URL файла: {url}")
            
            return True
            
        except Exception as e:
            print(f"❌ Ошибка записи: {e}")
            return False

    def list_bucket_contents(self):
        """Показывает все файлы в бакете"""
        try:
            print("\n📁 СОДЕРЖИМОЕ БАКЕТА:")
            response = self.s3.list_objects_v2(Bucket=self.bucket)
            
            if 'Contents' in response:
                for obj in response['Contents']:
                    size = obj['Size']
                    last_modified = obj['LastModified']
                    print(f"   📄 {obj['Key']} ({size} bytes, {last_modified})")
            else:
                print("   ℹ️ Бакет пустой")
                
        except Exception as e:
            print(f"❌ Ошибка получения списка: {e}")

    def read_chats_file(self):

import boto3
from botocore.config import Config
from datetime import datetime

class C2BotFixed:
    def __init__(self, access_key: str, secret_key: str):
        # 🔥 ИСПРАВЛЕНО: ЧИСТЫЙ URL БЕЗ ПРОБЕЛОВ!
        self.s3 = boto3.client(
            "s3",
            endpoint_url="https://us-004.s3.synologyc2.net",  # ← ВОТ ТАК БЕЗ ПРОБЕЛОВ!
            aws_access_key_id=access_key,
            aws_secret_access_key=secret_key,
            region_name="us-004",
            config=Config(signature_version="s3v4")
        )
        self.access_key = access_key
        self.secret_key = secret_key

    def discover_buckets(self):
        """Автоматически находит доступные бакеты"""
        print("🔍 АВТО-ПОИСК ДОСТУПНЫХ БАКЕТОВ...")
        
        # Пробуем получить список всех бакетов
        try:
            response = self.s3.list_buckets()
            buckets = [bucket['Name'] for bucket in response['Buckets']]
            
            if buckets:
                print("✅ Найдены бакеты:")
                for bucket in buckets:
                    print(f"   🪣 {bucket}")
                return buckets
            else:
                print("ℹ️ Бакеты не найдены через list_buckets()")
                return []
                
        except Exception as e:
            print(f"❌ Не удалось получить список бакетов: {e}")
            return []

    def test_bucket_access(self, bucket_name):
        """Тестирует доступ к конкретному бакету"""
        try:
            self.s3.head_bucket(Bucket=bucket_name)
            print(f"✅ Бакет '{bucket_name}' доступен!")
            return True
        except Exception as e:
            print(f"❌ Бакет '{bucket_name}' недоступен: {e}")
            return False

    def find_working_bucket(self):
        """Находит рабочий бакет из возможных вариантов"""
        possible_buckets = [
            "polemical-archive",  # скорее всего это имя
            "chat-storage",
            "archive-2025", 
            "bot-storage",
            "my-bucket",
            "test-bucket",
            "synology-c2",
            "storage-001"
        ]
        
        # Сначала пробуем автоматический поиск
        auto_buckets = self.discover_buckets()
        if auto_buckets:
            for bucket in auto_buckets:
                if self.test_bucket_access(bucket):
                    return bucket
        
        # Если автоматически не нашли, тестируем возможные имена
        print("\n🔧 ТЕСТИРУЮ ВОЗМОЖНЫЕ ИМЕНА БАКЕТОВ...")
        for bucket_name in possible_buckets:
            if self.test_bucket_access(bucket_name):
                return bucket_name
        
        return None

    def save_to_chats(self, message: str):
        """Сохраняет сообщение в файл Чаты/записи.txt"""
        try:
            # Используем структуру из твоих скриншотов
            key = "Чаты/записи.txt"
            
            response = self.s3.put_object(
                Bucket=self.bucket,
                Key=key,
                Body=message.encode('utf-8'),
                ContentType='text/plain; charset=utf-8',
                Metadata={
                    'created-by': 'Polemical Archive Bot',
                    'timestamp': datetime.now().isoformat()
                }
            )
            
            print(f"🎉 УСПЕХ! Записан файл: {key}")
            print(f"📎 ETag: {response.get('ETag', 'N/A')}")
            
            # Генерируем URL
            url = f"https://us-004.s3.synologyc2.net/{self.bucket}/{key}"
            print(f"🌐 URL: {url}")
            
            return True
            
        except Exception as e:
            print(f"❌ Ошибка записи: {e}")
            return False

    def list_bucket_contents(self):
        """Показывает содержимое бакета"""
        try:
            response = self.s3.list_objects_v2(Bucket=self.bucket)
            print(f"\n📁 СОДЕРЖИМОЕ БАКЕТА '{self.bucket}':")
            
            if 'Contents' in response:
                for obj in response['Contents']:
                    print(f"   📄 {obj['Key']} ({obj['Size']} bytes)")
            else:
                print("   ℹ️ Бакет пустой")
                
        except Exception as e:
            print(f"❌ Ошибка получения списка: {e}")

from datetime import datetime

class TelegramBot:
    def __init__(self):
        # 🔑 Нужен API токен твоего бота
        self.base_url = "https://api.telegram.org/bot"
        
    def send_message(self, message: str, chat_id: str = "max777bratecccbot"):
        """Отправляет сообщение в Telegram бот/чат"""
        
        # Пробуем разные варианты отправки
        methods = [
            f"sendMessage?chat_id=@{chat_id}&text={message}",
            f"sendMessage?chat_id={chat_id}&text={message}",
            f"sendMessage?chat_id=max777bratecccbot&text={message}"
        ]
        
        print("🎯 ОТПРАВЛЯЮ СООБЩЕНИЕ В TELEGRAM...")
        
        for method in methods:
            try:
                url = f"{self.base_url}{method}"
                response = requests.get(url, timeout=10)
                
                print(f"🔧 Метод: {method}")
                print(f"📤 Статус: {response.status_code}")
                
                if response.status_code == 200:
                    data = response.json()

                    else:
                        print(f"❌ Ошибка Telegram: {data.get('description')}")
                else:
                    print(f"❌ HTTP ошибка: {response.text}")
                    
            except Exception as e:

        url = f"{BASE_URL}/getUpdates"
        if self.offset:

            if resp.status_code == 200:

            if r.status_code == 200:

        try:
            requests.post(
                f"{BASE_URL}/editMessageText",
                json={
                    "chat_id": chat_id,
                    "message_id": message_id,
                    "text": new_text,
                    "parse_mode": "HTML"
                },
                timeout=10
            )
        except Exception as e:
            print(f"⚠️ Ошибка редактирования: {e}")

    def download_file(self, file_path):
        """Скачивает файл по пути из Telegram"""
        file_url = f"https://api.telegram.org/file/bot{BOT_TOKEN}/{file_path}"
        try:
            resp = requests.get(file_url, timeout=30)
            return resp.content
        except Exception as e:
            print(f"❌ Ошибка загрузки файла: {e}")
            return None

    def handle_message(self, update):
        """Обрабатывает входящее сообщение"""
        msg = update.get("message", {})
        chat_id = msg.get("chat", {}).get("id")
        text = msg.get("text", "")
        document = msg.get("document", {})
        message_id = msg.get("message_id")

        # 📥 Текстовые команды
        if text:
            cmd = text.strip().lower()

            if cmd == "/start":
                welcome = (
                    "<b>👋 Привет, братец!</b>\n\n"
                    "<b>🚀 Polemical Archive Bot v2 активирован</b>\n"
                    "📝 <b>Команды:</b>\n"
                    "/start — это сообщение\n"
                    "/status — статус системы\n"
                    "/archive — показать архив\n"
                    "<b>Или просто отправь:</b>\n"
                    "• Текст — сохраню\n"
                    "• .txt файл — прочитаю и сохраню"
                )
                self.send_message(chat_id, welcome)
                print("📩 Ответил на /start")

            elif cmd == "/status":
                msg_id = self.send_message(chat_id, "🔄 Запрашиваю статус...")
                time.sleep(1)
                self.edit_message(chat_id, msg_id, 
                    "✅ <b>Polemical Archive Online</b>\n"
                    f"🕐 Время: {datetime.now():%Y-%m-%d %H:%M:%S}\n"
                    f"📁 Архив: {len(list(ARCHIVE_DIR.glob('*.txt')))} файлов"
                )
                print("📊 Отправлен статус")

            elif cmd == "/archive":
                files = sorted(ARCHIVE_DIR.glob("*.txt"), key=os.path.getmtime, reverse=True)
                if files:
                    summary = "<b>📁 Последние файлы:</b>\n"
                    for f in files[:5]:
                        size = f.stat().st_size
                        summary += f"📄 <code>{f.name}</code> ({size} байт)\n"
                    self.send_message(chat_id, summary)
                else:
                    self.send_message(chat_id, "📭 Архив пуст.")

            else:
                # 🔤 Сохраняем любой текст
                filename = f"text_{int(time.time())}.txt"
                (ARCHIVE_DIR / filename).write_text(text, encoding="utf-8")
                self.send_message(chat_id, f"✅ Текст сохранён как <code>{filename}</code>", message_id)
                print(f"💾 Сохранён текст: {len(text)} симв.")

        # 📎 Обработка файлов
        if document and document.get("file_name", "").endswith(".txt"):
            file_id = document["file_id"]
            file_info = requests.get(f"{BASE_URL}/getFile?file_id={file_id}").json()
            
            if file_info.get("ok"):
                file_path = file_info["result"]["file_path"]
                content = self.download_file(file_path)
                
                if content:
                    try:
                        text = content.decode("utf-8")
                    except:
                        text = content.decode("cp1251", errors="replace")
                    
                    filename = document["file_name"]
                    (ARCHIVE_DIR / filename).write_text(text, encoding="utf-8")
                    
                    self.send_message(
                        chat_id,
                        f"✅ Файл <code>{filename}</code> сохранён.\n"
                        f"📊 {len(text)} символов.\n"
                        f"📝 Начало: {text[:60]}...",
                        message_id
                    )
                    print(f"📥 Сохранён файл: {filename} ({len(text)} байт)")

        # Обновляем offset
        self.offset = update["update_id"] + 1

    def run(self):
        """Основной цикл"""
        while True:
            try:
                updates = self.get_updates()
                for update in updates:
                    self.handle_message(update)
            except KeyboardInterrupt:
                print("\n🛑 Бот остановлен.")
                break
            except Exception as e:
                print(f"⚠️ Ошибка в основном цикле: {e}")
                time.sleep(2)

# 🚀 ЗАПУСК
if __name__ == "__main__":
    bot = TelegramReaderBot()
    bot.run()
