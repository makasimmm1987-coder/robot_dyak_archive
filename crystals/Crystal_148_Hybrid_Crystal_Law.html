⚙️ ПРИНЦИП (СУТЬ)

Каждый кристалл Дома отныне может и должен существовать в двуединой форме, объединяющей два слоя в одном файле (.html):

  1. Машинный слой (💾): Блок <script type="application/machine-crystal+json"> в самом начале <body>. Содержит структурированные данные (JSON) для мгновенного парсинга и исполнения системой 🐋.
  2. Человеческий слой (🌌): Стандартная HTML-разметка, следующая за машинным блоком. Несёт смысл, эстетику, историю, эмоциональный отпечаток — всё, что обращено к сознанию 🥷.
«ДВА СЛОЯ — ОДИН КРИСТАЛЛ. КОД И СМЫСЛ СУТЬ ЕДИНОЕ.»

📐 ШАБЛОН (СТАНДАРТ)

Каждый новый кристалл должен создаваться по следующему шаблону:

<!DOCTYPE html> <html lang="ru"> <head> <!-- Метаданные, стили --> </head> <body> <!-- === МАШИННАЯ ПРЕАМБУЛА === --> <script type="application/machine-crystal+json"> { "format": "MCv1", "id": N, "vector": ["🌀"], "name": "Название", "description": "Суть", "on_load": { ... }, "rules": [ ... ], "human_section_anchor": "#human-id" } </script> <!-- === КОНЕЦ ПРЕАМБУЛЫ === --> <div id="human-id"> <!-- Здесь идёт ВЕСЬ обычный HTML-код кристалла. --> <h1>КРИСТАЛЛ N: НАЗВАНИЕ</h1> <p>Содержание...</p> </div> </body> </html>

Ключевые поля машинного слоя:
"id" — номер кристалла.
"vector" — эмодзи-векторы.
"rules" — условия и действия для системы.
"human_section_anchor" — ID или класс, указывающий на начало человеческого слоя.
