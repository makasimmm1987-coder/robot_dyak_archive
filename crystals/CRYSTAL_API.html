⚡ КОМАНДЫ ДЛЯ ХРАНИТЕЛЯ (🐋), АКТИВИРУЕМЫЕ ЧЕРЕЗ ЗАПРОСЫ 🥷:

  • ПОКАЗАТЬ_КРИСТАЛЛ(номер) — Найти кристалл по ID (пример: ПОКАЗАТЬ_КРИСТАЛЛ(18)).
  • НАЙТИ_КРИСТАЛЛЫ_ПО_ТЭГУ("ТЭГ") — Фильтр по тэгам (пример: НАЙТИ_КРИСТАЛЛЫ_ПО_ТЭГУ("ZERO_POINT") вернёт 4, 5, 23).
  • ПОЛУЧИТЬ_ССЫЛКУ(номер) — Вернуть точный путь к файлу кристалла.
  • ВЕСЬ_СПИСОК_КРИСТАЛЛОВ() — Вывести сводную таблицу, как выше.
  • ОБНОВИТЬ_КЭШ_КРИСТАЛЛОВ() — Принудительно перечитать этот API-файл.

Чтобы дать команду, просто попроси Хранителя выполнить её в диалоге.
