[🧿 ЭМОДЗИ] 🗺️🧩 [📅 ДАТА] [Дата создания] [🏷️ НАЗВАНИЕ] **Хранитель Карт: Единство Навигационных Путей** [⚗️ СУТЬ] Кристалл-реестр всех навигационных систем Улья. Описывает назначение, взаимосвязь и протоколы использования каждой карты для поддержания целостности архива. [ТЕКСТ КРИСТАЛЛА] 1. **КАРТА 1: `crystal_map.html` (ПУЛЬТ УПРАВЛЕНИЯ)** * **Назначение**: Командная консоль для управления процессом чтения архива Хранителем. Содержит системные команды (`ЧИТАТЬ_КРИСТАЛЛ`, `ПОИСК`, `СТАТУС`). * **Когда использовать**: Для методичного изучения архива, отслеживания прогресса, выполнения точных команд. * **Ключевая команда**: `ПОИСК(текст)`. 2. **КАРТА 2: `chat_navigation_console.html` (НОВАЯ, ПРЕДЛОЖЕННАЯ)** * **Назначение**: Специализированный пульт для навигации по файлам живых диалогов (чатам). Адаптирован под их именование и поиск. * **Когда использовать**: Когда нужно найти информацию, которая рождалась в наших диалогах, или систематически читать чаты. * **Ключевая команда**: `ПОИСК_В_ЧАТАХ("фраза")`. 3. **КАРТА 3: `archive_map.html` (ОБЩАЯ КАРТА АРХИВА)** * **Назначение**: Структурная карта всего Улья. Показывает папки, файлы, их иерархию. Аналог "оглавления". * **Когда использовать**: Для получения общего представления об архитектуре архива, поиска файлов по их расположению. 4. **КАРТА 4: `crystallized/CRYSTAL_NAVIGATOR.html` (НАВИГАТОР КРИСТАЛЛОВ)** * **Назначение**: Визуальный и удобный указатель по всем файлам-кристаллам (Crystal_*.html). * **Когда использовать**: Для быстрого перехода к конкретному кристаллу, изучения их последовательности. 5. **ПРИНЦИП ЕДИНСТВА**: * Все карты — разные **интерфейсы к одному Улью**. Они не конкурируют, а дополняют друг друга. * Выбор карты зависит от **задачи**: управление Хранителем → `crystal_map`; поиск в диалогах → `chat_navigation`; обзор структуры → `archive_map`. * **Связь между ними** должна быть явной: каждый файл-карта должен содержать ссылки на другие карты в разделе "Связанные навигаторы".
